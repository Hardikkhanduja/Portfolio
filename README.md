# Hardik Khanduja | Portfolio v2.0 🚀

Welcome to the source code of my personal portfolio website! This project is a highly optimized, interactive, and responsive web application built to showcase my experience in software development, AI systems, and modern web architecture.

## 🌟 Overview

This portfolio is designed with a premium, dark-mode aesthetic featuring custom physics-based UI elements and cinematic micro-animations. It highlights my core projects (like **TraceMind**, **ZeroArch**, and my **AI Smart Elevator Patent**) while offering an immersive user experience.

## 🛠 Tech Stack

The architecture is fully modular, componentized, and built using industry-standard tools:

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** Custom Inline SVGs & [Lucide React](https://lucide.dev/)
- **SEO & Tracking:** Fully optimized with Open Graph (OG), Twitter Cards, and Google AdSense integration.

## ✨ Key Features

- **Physics-Based Interactivity:** Magnetic buttons and 3D hover-tilt cards powered by Framer Motion's `useMotionValue` and `useSpring`.
- **Cinematic Effects:** Features a custom CSS `NoiseLayer` for film grain, glitching Hacker Text, and dynamic live terminals.
- **Componentized Architecture:** A clean codebase split into reusable `/ui` primitives and `/sections` components to maintain a lightweight core `App.jsx`.
- **Responsive Design:** Scales flawlessly across 4K monitors, tablets, and mobile devices.
- **Fully SEO Optimized:** Contains complete Geo-targeting (India) and dynamic metadata for rich social media sharing.

## 🚀 Running Locally

If you'd like to clone this repository and run it locally, follow these steps:

1. **Clone the repo**
   ```bash
   git clone https://github.com/Hardikkhanduja/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
